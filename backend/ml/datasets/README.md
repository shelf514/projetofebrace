# Datasets para treinamento do modelo de ML

Coloque aqui datasets reais em formato CSV, XLSX ou JSON.

## AVISO IMPORTANTE

- **`demo_mock.csv`** e um dataset **SINTETICO** gerado apenas para testar a
  aplicacao de ponta a ponta. **NUNCA** apresente este dataset nem os resultados
  treinados com ele como dados cientificos reais.
- Datasets reais devem ter sua origem e licenca registradas em `docs/methodology.md`
  antes de serem usados.
- O dataset deve conter uma variavel-alvo para classificacao (categorica) ou
  regressao (numerica). Se o dataset real nao tiver uma variavel-alvo adequada,
  nao invente labels: use apenas a deteccao de anomalias.
